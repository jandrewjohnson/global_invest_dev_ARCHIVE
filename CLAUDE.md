# global_invest_dev

Global InVEST-style ecosystem-service / economic modeling. Part of the
earth-economy devstack; builds on the shared **hazelbean** base library
(`import hazelbean as hb`).

Shared devstack guidance (reuse rule + ownership map + EE conventions pointer) is
imported below — before adding any general utility, search hazelbean first and
reuse/extend rather than duplicate.

@../../earth_economy_devstack/devstack_guidance.md

## Environment

Conda-based. Activate the project environment before running code
(confirm the correct env name for your machine).
